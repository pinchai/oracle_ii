# Oracle SEQUENCE and Options

A **SEQUENCE** in Oracle is a database object that automatically
generates unique numeric values. It is commonly used to generate
**primary key IDs**.

## Syntax

``` sql
CREATE SEQUENCE sequence_name
    START WITH n
    INCREMENT BY n
    MINVALUE n
    MAXVALUE n
    [CYCLE | NOCYCLE]
    [CACHE n | NOCACHE];
```

## Example

``` sql
CREATE SEQUENCE seq_student
    START WITH 1000
    INCREMENT BY 10
    MINVALUE 1000
    MAXVALUE 9999
    CYCLE
    CACHE 20;
```

Generated values:

``` text
1000
1010
1020
1030
1040
...
9990
1000   -- Starts over because of CYCLE
```

## SEQUENCE Options

  -----------------------------------------------------------------------
  Option               Description                   Example
  -------------------- ----------------------------- --------------------
  **START WITH**       First number generated by the `START WITH 1000`
                       sequence.                     

  **INCREMENT BY**     Amount added (or subtracted)  `INCREMENT BY 10`
                       for each new value.           

  **MINVALUE**         Smallest value the sequence   `MINVALUE 1000`
                       can generate.                 

  **MAXVALUE**         Largest value the sequence    `MAXVALUE 9999`
                       can generate.                 

  **CYCLE**            Restarts from `MINVALUE`      `CYCLE`
                       after reaching `MAXVALUE`.    

  **NOCYCLE**          Stops at `MAXVALUE` and       `NOCYCLE`
                       raises an error on the next   
                       request.                      

  **CACHE**            Stores sequence values in     `CACHE 20`
                       memory for better             
                       performance.                  

  **NOCACHE**          Disables caching.             `NOCACHE`

  **ORDER**            Guarantees request order      `ORDER`
                       (mainly Oracle RAC).          

  **NOORDER**          Better performance without    `NOORDER`
                       ordering guarantee.           
  -----------------------------------------------------------------------

## Using NEXTVAL

``` sql
SELECT seq_student.NEXTVAL
FROM dual;
```

## Using CURRVAL

> `CURRVAL` is available only after `NEXTVAL` has been called in the
> current session.

``` sql
SELECT seq_student.CURRVAL
FROM dual;
```

## Insert Example

``` sql
CREATE TABLE student (
    student_id NUMBER PRIMARY KEY,
    name VARCHAR2(100)
);

INSERT INTO student (student_id, name)
VALUES (seq_student.NEXTVAL, 'Alice');
```

## Alter a Sequence

``` sql
ALTER SEQUENCE seq_student
INCREMENT BY 5
MAXVALUE 20000
CACHE 50;
```

> `START WITH` cannot be changed after the sequence is created.

## Drop a Sequence

``` sql
DROP SEQUENCE seq_student;
```

## Ascending Sequence

``` sql
CREATE SEQUENCE seq_order
START WITH 1
INCREMENT BY 1;
```

## Descending Sequence

``` sql
CREATE SEQUENCE seq_countdown
START WITH 100
INCREMENT BY -5
MINVALUE 0;
```

## Best Practices

-   Use **NOCYCLE** for primary keys.
-   Use **CACHE** (20--100) for better performance.
-   Use **NOORDER** unless Oracle RAC ordering is required.
-   Use **NEXTVAL** for inserts and **CURRVAL** only after **NEXTVAL**
    has been called.

## Summary

  Option            Default                Purpose
  ----------------- ---------------------- -------------------
  START WITH        1                      Starting value
  INCREMENT BY      1                      Step size
  MINVALUE          Depends on increment   Lowest value
  MAXVALUE          Depends on increment   Highest value
  CYCLE / NOCYCLE   NOCYCLE                Restart or stop
  CACHE / NOCACHE   CACHE 20 (typical)     Performance
  ORDER / NOORDER   NOORDER                Ordering behavior
